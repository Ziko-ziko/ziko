# video-studio

Video editing / motion graphics toolkit (Remotion + ffmpeg + Python). See README.md for tools.

## Client styles
- **SALMA GLOW**: house style for Salma's videos. Read `styles/SALMA_GLOW.md` before editing any video
  for Salma, or whenever the user says "SALMA GLOW" / "ستايل سلمى". Apply all of its rules,
  especially: animations start exactly on the spoken word (measure with `scripts/asr_window.py`).
